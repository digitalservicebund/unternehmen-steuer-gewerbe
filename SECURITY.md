# 🇩🇪 Schwachstellen / Sicherheitslücken

Sicherheit spielt in diesem Projekt eine große Rolle. Wir achten sehr darauf, den Code sicher zu machen, aber Schwachstellen können immer auftreten. Wir sind allen dankbar, die uns potenzielle Schwachstellen vertraulich mitteilen.

## Schwachstellen mitteilen (Disclosure)

Alle sicherheitsrelevanten Hinweise bitte an [security@digitalservice.bund.de](mailto:security@digitalservice.bund.de).

- Senden Sie so viele Informationen wie möglich - auch Details können hilfreich sein.
- Wenn möglich: Teilen Sie uns mit, um welches Release oder welchen Commit es sich handelt.
- Nutzen Sie unseren [public key](https://raw.githubusercontent.com/digitalservicebund/public-keys/main/pgp-public-key-security-mail.pem) für verschlüsselte E-Mail.

**Teilen Sie uns Schwachstellen nicht über GitHub "issues" mit**, da dies die Schwachstelle unmittelbar öffentlich machen würde!

## Was passiert nach der Mitteilung?

- Wir untersuchen, ob die Mitteilung tatsächlich ein Sicherheitsproblem beschreibt.
- Falls sich das bestätigt, klären wir die Relevanz und mögliche Lösungen.
- Wenn es möglich ist, halten wir Sie über relevante Fortschritte auf dem Laufenden.

# 🇬🇧 Security Vulnerabilities

Security is a top priority for this project. We actively work to keep the
codebase secure, but vulnerabilities can still occur. We appreciate everyone
who reports potential security issues responsibly.

## Disclosing security issues

Please send any security concerns to [security@digitalservice.bund.de](mailto:security@digitalservice.bund.de).

- Include as much information as possible - even small details may be helpful
- Add the affected release version / commit if possible
- You may use our [public key](https://raw.githubusercontent.com/digitalservicebund/public-keys/main/pgp-public-key-security-mail.pem) to encrypt your mail

**Do not** report security vulnerabilities through GitHub issues, as this publicly discloses the vulnerability immediately!

## What happens after disclosure

- We assess whether the report describes a valid security issue.
- If confirmed, we assess impact and a possible fix.
- We keep you informed about relevant progress when possible.
