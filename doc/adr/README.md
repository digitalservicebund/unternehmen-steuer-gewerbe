# Architecture Decision Records (ADR)

As this codebase is part of a larger project, there are two locations for ADRs:

1. ADRs of this code base can be found in the same folder as this README (https://github.com/digitalservicebund/unternehmen-steuer-gewerbe/doc/adr).
1. ADRs that for the parent project "Schnelle Gründen" can be found in the repository of "Unternehmen One-Stop-Shop" at https://github.com/digitalservicebund/unternehmen-one-stop-shop/tree/main/docs/adr.
