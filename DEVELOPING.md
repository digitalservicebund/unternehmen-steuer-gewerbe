# Developing

## Running the API

```bash
pnpm start
```

or in watch mode, restarting on changes

```bash
pnpm run start:watch
```

## Running the Tests

```bash
pnpm run test
```

or in watch mode, restarting on changes

```bash
pnpm run test:watch
```

## Using GitHooks

Requires [lefthook](https://lefthook.dev/)

```bash
lefthook install
```
