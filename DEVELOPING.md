# Developing

## Running the API

```bash
pnpm start
```

or in watch mode, restarting on changes

```bash
pnpm run start:watch
```

## Running the Tests

```bash
pnpm run test
```

or in watch mode, restarting on changes

```bash
pnpm run test:watch
```

## Using Git Hooks

We're using [lefthook](https://lefthook.dev/) for Git hook configuration. After installing `lefthook`, run the following once:

```bash
lefthook install
```
